# Calculadora IMC

Este repositorio contiene el código fuente del proyecto Calculadora de Índice de Masa Corporal (IMC).

## Requisitos Previos

* [Git](https://git-scm.com/downloads)
* [Java JDK](https://www.oracle.com/java/technologies/downloads/) (Versión 11 o superior)
* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/)

## Instalación y Configuración

Siga estos pasos para clonar y ejecutar el proyecto en su entorno local:

### 1. Clonar el repositorio

Abra la terminal o línea de comandos y ejecute la siguiente instrucción:

    git clone https://github.com/RobertoMartinezDiaz/CalculadorIMC.git

### 2. Abrir el proyecto en IntelliJ IDEA

1. Abra IntelliJ IDEA.
2. Seleccione **File > Open** en el menú superior.
3. Busque y seleccione la carpeta `CalculadorIMC` que se generó al clonar el repositorio.
4. Haga clic en **OK**.
5. Si el sistema lo solicita, seleccione **Trust Project** y espere a que el IDE termine de indexar los archivos.

### 3. Ejecutar la aplicación

1. En el panel lateral izquierdo (Project view), expanda la carpeta `src`.
2. Ubique el archivo principal del programa (la clase que contiene el método `main`).
3. Haga clic derecho sobre el archivo y seleccione **Run**.
